# robs-atv01
Unidade I – Webapps

Desenvolver uma página web estática interativa, com foco em estruturação semântica, estilização visual responsiva, acessibilidade e início da interatividade com JavaScript. A proposta é criar uma experiência simples, mas completa, integrando os principais pilares da construção de uma interface web moderna.

📌 Requisitos obrigatórios
🧱 Estrutura em HTML5
Uso correto das tags semânticas: <header>, <main>, <section>, <article>, <footer>.

Inclusão de:

Título da página <title>

Texto de apresentação (<h1>, <p>)

Lista (<ul> ou <ol>)

Links com <a> (para redes sociais ou e-mail)

Mídia: <img>, <audio> ou <video> com descrição textual

Campo de formulário simples (ex: input de e-mail ou nome)

🎨 Estilização com CSS3
CSS externo (style.css) com organização clara e comentada

Aplicar:

Layout com Flexbox (ex: menu ou seções lado a lado)

Cores, fontes, margens e paddings personalizados

Efeitos de hover simples (ex: em botões ou links)

Responsividade básica para dispositivos móveis

🧠 Inclusão de JavaScript (JS básico)
Arquivo JS externo (script.js)

Pelo menos duas funcionalidades básicas, por exemplo:

Exibir uma saudação com alert()

Mostrar ou esconder uma seção com addEventListener()

Alterar dinamicamente o conteúdo de um elemento com innerText ou innerHTML

Coletar e exibir dados inseridos em um campo (prompt, value)

document.getElementById("btn").addEventListener("click", function () {
  alert("Olá! Obrigado por visitar meu currículo.");
});
🖼️ Canvas (opcional, mas recomendado)
Criar um pequeno gráfico ou forma com <canvas> como enfeite visual ou ilustração de habilidade.

📁 Organização sugerida dos arquivos
/curriculo/
├── index.html
├── style.css
├── script.js
└── /media/
    ├── foto.jpg

🧪 Exemplo de funcionalidades com JS
Botão que exibe uma mensagem de boas-vindas;

Campo de nome que, ao ser preenchido, aparece como saudação no topo da página;

Clique para mudar cor de fundo ou imagem exibida;

Um contador de visitas local usando localStorage.

Rubrica de Avaliação (Nota Final: 0 a 10)
Critério	Pontuação	Descrição
1. Estrutura semântica com HTML	2,0 pts	Uso adequado de tags (<header>, <main>, <section>, etc.) e organização.
2. Estilização com CSS	2,0 pts	CSS externo, layout com flexbox, cores, fontes, efeitos simples.
3. Inclusão e uso de mídias	1,0 pt	Inserção correta de imagens, vídeo ou áudio com descrições.
4. Funcionalidades com JavaScript básico	2,0 pts	Pelo menos 2 interações simples: alert, toggle, innerText, etc.
5. Publicação da página online	1,0 pt	Página publicada e funcionando corretamente em um dos serviços propostos.
6. Organização e clareza do código	1,0 pt	Arquivos organizados, identação adequada, uso de comentários.
7. Criatividade e identidade visual	1,0 pt	Visual atrativo, layout cuidado e conteúdo personalizado.
